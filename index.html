Market Lantern

An AI-powered equity research mobile app with an in-app assistant that answers market questions by calling tools against live research data.

The problem

Equity research is spread across quotes, earnings calendars, news, filings, and trade disclosures. Looking that up usually means leaving a research view and searching in several places.

Market Lantern brings those sources into one mobile app. The AI assistant is there so a user can ask a question in plain language and get an answer grounded in the app’s own market data, or in a web search when the database does not have it.

What it does

The mobile app is a professional equity research client. Alongside the assistant, it includes:

Quotes and chartsLive quotes, historical bars, company profiles, and custom interactive charts.
FundamentalsFinancials, ratios, analyst estimates, and related analysis views.
News and filingsNews feeds, SEC filings, insider Form 4 activity, and congressional trade disclosures.
Market contextMarket status, movers, sector performance, a Fear and Greed index, earnings and economic calendars, and options data.
Portfolios and watchlistsSaved lists and portfolio views, with market-aware background sync while markets are open.
CommunityProfiles, friends, messaging, posts, and courses.

This page describes the product and the AI assistant at a high level. It does not include source code, environment files, API keys, or internal service URLs.

How the AI works

The in-app chat, labeled Market Lantern AI, talks to a Python FastAPI agent. The model can answer directly, or it can call tools when the question is about market data.

1

The user asks a question in the app

The chat screen sends the message to the agent’s chat endpoint. Replies come back as text and are rendered as Markdown.

2

The agent decides whether tools are needed

Short greetings are answered directly. If the message looks like a data request (price, earnings, news, market status, fundamentals, and similar terms), the model is allowed to call tools. Otherwise it answers without them.

3

Tools fetch facts, then the model writes the reply

Supported tools look up market status, search stocks, get earnings for a symbol or for today, and fetch stored market news. A web search tool is used when the answer is not in the database. Tool results are truncated before they go back to the model, and a second pass turns them into a customer-facing answer. The assistant is instructed to speak directly to the user and not to show internal reasoning.

System prompt (from the project)

You are “Market Lantern AI”, a professional financial assistant for Market Lantern customers. Speak directly to the user. Be helpful, polite, and professional. Do not output internal monologue or thoughts. Just output the response. Use tools only when needed for data (price, news, earnings). If no tool is needed, respond normally.

Tech stack

Expo SDK 54 React Native TypeScript Python FastAPI OpenRouter Function calling / tools Convex Clerk Financial Modeling Prep Alpaca Markets SVG charts

The default hosted model in the agent is configurable in code. The project’s current default is Xiaomi Mimo V2 Flash via OpenRouter, with optional Groq or local Ollama paths.
